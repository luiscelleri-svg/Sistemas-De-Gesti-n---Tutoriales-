# Sistema de Gestión de Tutorías Académicas

## Descripción

Proyecto académico orientado al desarrollo de un sistema para gestionar tutorías académicas dentro de una universidad.

El sistema permitirá a los estudiantes solicitar tutorías, seleccionar docentes, consultar horarios disponibles y confirmar o cancelar citas. Además, permitirá registrar observaciones y gestionar información relacionada con las tutorías.

## Objetivo

Diseñar una solución que facilite la organización y seguimiento de las tutorías académicas, centralizando la información de estudiantes, docentes, horarios y citas.

## Funcionalidades principales

* Solicitud de tutorías académicas.
* Selección de docentes.
* Consulta de horarios disponibles.
* Confirmación de citas.
* Cancelación de citas.
* Registro de observaciones.
* Gestión de información para reportes.

## Estructura del proyecto

* `docs/` - Documentación general del proyecto.
* `requisitos/` - Requisitos funcionales y no funcionales.
* `modelos/` - Modelos y diagramas del sistema.
* `src/` - Código fuente del proyecto.
* `pruebas/` - Documentación y evidencias de pruebas.

## Gestión del proyecto

El seguimiento de las actividades del proyecto se realiza mediante un tablero de Trello organizado en las etapas:

**Por hacer → En proceso → En revisión → Hecho**
